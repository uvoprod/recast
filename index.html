      Where your file goes

      Short answer: nowhere. Here is exactly what moves and what doesn't.

      The conversion code runs on your own device, so there is no server for your files to reach.

      The first time you use a kind of file, the page downloads that converter's code from a public library host (cdnjs, jsDelivr or unpkg). Those requests carry only the address of the code, never your file.

      Because nothing is uploaded, the only limits are your device's memory and processor. A phone may struggle with a 500-page PDF at 300 dpi; a laptop usually won't.

      Questions

      About formats, file sizes, quality and privacy.

      Is there a file size or file count limit?

      Recast sets no limit. Files are processed in your browser's memory, so the practical ceiling is your device. Files in a batch are converted one after another, so a long batch is fine; a single huge file (hundreds of megabytes, or a PDF with hundreds of pages at high sharpness) can be slow or fail on a phone.

      Will a PDF keep its layout when I turn it into Word or Markdown?

      Recast rebuilds the text: headings, paragraphs and bullet lists come across, worked out from the font sizes in the PDF. Multi-column layouts, exact fonts and pictures are not kept. If you need the page exactly as it looks, convert the PDF to images instead.

      Scanned PDFs are pictures of pages with no text inside, so there's nothing to extract. Recast tells you when that happens.

      What does a document look like when I turn it into a PDF?

      It's typeset fresh with clean, consistent styling: headings, lists, tables, quotes, code and pictures carry over, but the original's fonts and spacing don't. Text in scripts outside Western European alphabets (Bengali, Chinese, Arabic and so on) is saved as page images so it displays correctly; that text can't be selected in the PDF.

      Why can't I save as HEIC or AVIF?

      Browsers can read these formats but can't write them, so Recast offers JPEG, PNG or WebP instead. WebP needs Chrome, Edge or Firefox; Safari can't create it.

      Why do some files arrive in a .zip?

      Converting a multi-page document to images gives one image per page, so they're bundled into one .zip.

      Does it work offline?

      Recast needs a connection the first time each kind of converter is used, to download its code. The conversion itself happens on your device.

      Are my files private?

      Yes. Files never leave this tab, and closing it discards them. The only network requests the page makes are for its fonts and converter code.

      Just say what you want.

      Attach files and type it the way you'd say it. Recast works out the formats, combines what you ask it to, and hands you the result. It reads your words with simple rules on this device, and nothing you type or attach leaves this tab.
